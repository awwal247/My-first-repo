// Features

Everything you need. Nothing you don't.

Built lean on purpose — fast, deployable, and extensible.

🧠

Persistent Vector Memory

TF-IDF + cosine similarity retrieves your most relevant past exchanges per mode. Accessible as a sidebar even after logout.

🔍

Real-time Web Search

Researcher mode fetches live Tavily results and injects them directly into the AI prompt for grounded, current answers.

👁️

OCR Image Analysis

Upload any image — Tesseract OCR extracts the text and passes it to the AI as readable context. No external vision API needed.

📎

Universal File Upload

PDF, DOCX, XLSX, PPTX, CSV, JSON, code files, ZIP/RAR archives — content is extracted and injected into any mode's prompt.

🔐

Secure Auth

Email + password (Werkzeug salted hashes) or optional Google OAuth. Accounts from both methods share the same record.

💾

Download Outputs

Slides Generator produces real .pptx files. Developer mode packages code blocks into a .zip for immediate download.
